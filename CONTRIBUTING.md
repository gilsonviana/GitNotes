# Contributing to GitNotes

Thank you for your interest in contributing to GitNotes! This document provides guidelines for contributing to the project.

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/your-username/GitNotes.git`
3. Install dependencies: `npm install`
4. Create a feature branch: `git checkout -b feature/your-feature-name`

## Development Workflow

1. Make your changes
2. Test your changes locally with `npm run dev`
3. Build the project to ensure it compiles: `npm run build`
4. Commit your changes with a descriptive message
5. Push to your fork
6. Create a Pull Request

## Code Style

- Follow the existing code style in the project
- Use meaningful variable and function names
- Add comments for complex logic
- Keep functions small and focused

## Testing

- Test your changes thoroughly before submitting
- Ensure the app builds successfully
- Test offline functionality if your changes affect it

## Pull Request Guidelines

- Provide a clear description of the changes
- Reference any related issues
- Ensure your code builds without errors
- Keep PRs focused on a single feature or fix

## Questions?

Feel free to open an issue if you have any questions about contributing!
